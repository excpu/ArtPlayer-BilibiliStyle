# artplayer-plugin-danmuku

Danmuku plugin for ArtPlayer

## Demo

[https://artplayer.org](https://artplayer.org/?libs=./uncompiled/artplayer-plugin-danmuku/index.js&example=danmuku)

## Speed

Set `speed` to `'fast'`, `'normal'`, or `'slow'`. At `'normal'`, a scrolling danmu crosses the player in about 8 seconds in a small window and about 13 seconds in fullscreen (interpolated by player width), similar to Bilibili. `'fast'` and `'slow'` scale that duration. The default is `'normal'`.
